# Λύση Προβλήματος Λογικού Ψηφιακού Σχεδιασμού

## Περιγραφή

Αυτό το πρόβλημα αφορά τον σχεδιασμό μιας βάσης δεδομένων για ένα σύστημα διαχείρισης εγγράφων και χώρων εργασίας.

## Αρχιτεκτονική

Το διάγραμμα ERD περιγράφει τις ακόλουθες κύριες οντότητες:

### Κύριες Οντότητες

1. **ΧΡΗΣΤΗΣ (User)**
   - username (Primary Key)
   - email
   - password
   - όνομα
   - θέση
   - τηλ. επικοινωνίας

2. **ΧΩΡΟΣ ΕΡΓΑΣΙΑΣ (Workspace)**
   - κωδικός_ΧΩΡΟΥ (Primary Key)
   - τίτλος
   - ΗΜΕΡΟΜΗΝΙΑ/ΩΡΑ

3. **ΑΝΤΙΚΕΙΜΕΝΟ (Object)**
   - ΚΩΔΙΚΟΣ_ΑΝΤΙΚΕΙΜΕΝΟΥ (Primary Key)
   - ΤΥΠΟΣ_ΑΝΤΙΚΕΙΜΕΝΟΥ
   - κωδικός
   - τίτλος
   - θέση
   - ΗΜΕΡΟΜΗΝΙΑ/ΩΡΑ

4. **ΓΝΩΣΙΑΚΟ ΑΝΤΙΚΕΙΜΕΝΟ (Knowledge Object)**
   - blob
   - κείμενο

5. **ΦΑΚΕΛΟΣ (Folder)**
   - όνομα

6. **ΣΥΝΤΟΜΕΥΣΗ (Shortcut)**
   - Αναφορά σε αντικείμενο

7. **ΛΥΣΗ (Solution)**
   - ΕΠΙΠΕΔΟ_ΣΙΓΟΥΡΙΑΣ

8. **ΠΡΟΒΛΗΜΑ (Problem)**
   - Βασική οντότητα για προβλήματα

9. **ΕΠΙΧΕΙΡΗΜΑ (Operation)**
   - ΤΥΠΟΣ_ΕΠΙΧΕΙΡΗΜΑΤΟΣ
   - ΒΑΘΜΟΣ_ΣΗΜΑΝΤΙΚΟΤΗΤΑΣ

10. **ΑΝΑΦΟΡΑ (Report)**
    - ΑΡΙΘΜΟΣ (Primary Key)
    - URL
    - ΗΜΕΡΟΜΗΝΙΑ/ΩΡΑ
    - ΑΠΟΤΕΛΕΣΜΑ

### Σχέσεις

- **ΧΡΗΣΤΗΣ** → ΔΗΜΙΟΥΓΕΙ → **ΧΩΡΟΣ ΕΡΓΑΣΙΑΣ** (1:N)
- **ΧΩΡΟΣ ΕΡΓΑΣΙΑΣ** → ΠΕΡΙΕΧΕΙ → **ΑΝΤΙΚΕΙΜΕΝΟ** (1:N)
- **ΑΝΤΙΚΕΙΜΕΝΟ** → ΣΧΕΤΙΖΕΤΑΙ → **ΑΝΤΙΚΕΙΜΕΝΟ** (N:M)
- **ΧΡΗΣΤΕΣ** → ΦΤΙΑΧΝΟΥΝ → **ΑΝΤΙΚΕΙΜΕΝΟ** (N:M)
- **ΦΑΚΕΛΟΣ** → ΠΕΡΙΛΑΜΒΑΝΕΙ → **ΑΝΤΙΚΕΙΜΕΝΟ** (1:N)
- **ΕΠΙΧΕΙΡΗΜΑ** → ΣΥΝΔΕΕΤΑΙ_1 → **ΛΥΣΗ** (N:M)
- **ΕΠΙΧΕΙΡΗΜΑ** → ΣΥΝΔΕΕΤΑΙ_2 → **ΠΡΟΒΛΗΜΑ** (N:M)
- **ΧΡΗΣΤΗΣ** → ΑΞΙΟΛΟΓΕΙ → **ΑΝΑΦΟΡΑ** (N:M)
- **ΑΝΑΦΟΡΑ** → ΑΝΤΙΣΤΟΙΧΙΖΕΤΑΙ → **ΧΩΡΟΣ ΕΡΓΑΣΙΑΣ** (N:1)

## Υλοποίηση

Το αρχείο `database_schema.sql` περιέχει την πλήρη υλοποίηση της βάσης δεδομένων με:
- Ορισμούς πινάκων
- Foreign keys
- Indexes για βελτιστοποίηση
- Πίνακες σχέσεων για N:M relationships

## Χρήση

Για να δημιουργήσετε τη βάση δεδομένων:

```bash
psql -U postgres -d your_database -f database_schema.sql
```

ή

```sql
\i database_schema.sql
```

## Σημειώσεις

- Το σχήμα υποστηρίζει PostgreSQL
- Για MySQL/MariaDB, αλλάξτε SERIAL σε AUTO_INCREMENT
- Για SQLite, αφαιρέστε τύπους SERIAL και χρησιμοποιήστε INTEGER
